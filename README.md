# 🌐 Personal Portfolio Website

## 📌 Project Description

This project is a **Personal Portfolio Website** developed as part of my **Web Development Internship at Synent Technologies**. It is designed to present my personal profile, technical skills, and contact information in a clean, organized, and visually appealing manner.

## 🎯 Purpose of the Project

The aim of this project is to build a professional portfolio using basic web technologies and to understand how a real-world personal website is structured.

## 🚀 Key Features

* Simple and user-friendly interface
* Clean and well-organized layout
* Different sections for better content presentation
* Responsive design for different screen sizes *(if you made it responsive)*

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

* **index.html** → Contains the main structure of the website
* **style.css** → Handles styling, layout, and design

## 📑 Sections Included

* **Header** → Displays name and title
* **About Me** → Introduction about myself
* **Skills** → Highlights my technical skills
* **Contact** → Provides contact details

## 📚 What I Learned

* Basics of HTML structure and semantic elements
* Styling web pages using CSS
* Creating layouts with proper alignment and spacing
* Designing a simple and effective user interface

## 📌 Conclusion

This project gave me a strong foundation in front-end development and helped me understand how to design and structure a personal portfolio website in a professional way.
